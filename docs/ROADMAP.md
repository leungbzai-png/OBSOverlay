# OBSOverlay 路线图 (ROADMAP)

当前版本：**v0.1.0**（项目化 + 去敏 + 配置外置）。

## 计划中的迭代方向

- **更好看的 Overlay UI**：圆角、阴影、动画、图标，更精致的视觉。
- **配置文件增强**：浮窗位置 / 大小 / 颜色 / 显示时长可配置。
- **快捷键开关**：全局热键显示 / 隐藏 / 测试提示。
- **多场景提示文本**：按 OBS 场景或自定义事件显示不同提示。
- **更深的 OBS WebSocket 联动**：直播状态、虚拟摄像头、回放缓存、统计信息。
- **打包为 exe**：用 PyInstaller 提供免装 Python 的版本。
- **托盘菜单增强**：重连、打开配置、查看状态等。
- **日志与异常提示**：可选的本地日志（不记录密码）与更友好的错误反馈。
- **主题与透明度设置**：明暗主题、透明度、置顶行为可调。

## 非目标 / 暂不考虑

- 跨平台（当前依赖 Windows 的 `WDA_EXCLUDEFROMCAPTURE`）。
- 重型 GUI 框架，保持轻量。
