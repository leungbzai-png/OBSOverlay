# OBSOverlay 路线图 (ROADMAP)

当前版本：**v0.1.0**——已实现状态悬浮提示、OBS WebSocket 联动与配置化、系统托盘常驻、
开机自启管理、OBS 自启管理、安全清理回归与安全配置模板（详见 README / CHANGELOG）。
本路线图只记录这些**基础能力之上的增强方向**，不再重复已实现功能。

## 计划中的增强方向

- **portable exe / PyInstaller 打包**：提供免装 Python 的单文件版本。
- **图形化配置界面**：用 GUI 编辑 host / port / password 等，免手改 `config.json`。
- **配置项扩展**：浮窗位置 / 大小 / 显示时长可配置。
- **自定义主题、颜色、透明度、位置**：明暗主题、置顶行为、圆角阴影等视觉调整。
- **托盘菜单增强**：重连、打开配置、查看连接状态等菜单项。
- **托盘图标状态变化**：按录制状态切换托盘图标 / 颜色。
- **更多 OBS 状态联动**：直播状态、虚拟摄像头、回放缓存、统计信息等。
- **多场景提示模板**：按 OBS 场景或自定义事件显示不同提示文本。
- **快捷键开关**：全局热键显示 / 隐藏 / 测试提示。
- **日志页面或错误诊断**：可选本地日志（不记录密码）与更友好的错误反馈。
- **自动更新或版本检查**：检测新版本并提示。
- **更完善的 release 自动化**：打包、扫描、生成 release notes 的脚本化流程。

## 非目标 / 暂不考虑

- 跨平台（当前依赖 Windows 的 `WDA_EXCLUDEFROMCAPTURE`）。
- 重型 GUI 框架，保持轻量。
